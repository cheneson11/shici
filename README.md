# 诗词拾遗

精选先秦至近代经典诗词的极简单文件网页应用：支持全文搜索、分类与作者筛选、随机推荐和已读标记。

> 纯前端单文件实现，无框架、无构建、无外部依赖，部署到 GitHub Pages 即可在线使用。

## ✨ 功能特性

- 📚 收录 **254 首** 经典诗词，涵盖 **8 大分类 · 111 位作者**
- 🔍 全文搜索（题目 / 作者 / 正文）
- 🏷️ 分类与作者折叠筛选，作者列表随当前分类动态生成
- 🎲 随机推荐：优先推荐未读篇目（权重 3:1），全部读过则等概率随机
- ✅ 已读标记：`localStorage` 本地持久化，支持一键取消所有已读标记
- 📊 已读统计：全部篇目 / 未读 / 已读
- 📱 响应式布局，支持添加到手机主屏幕（favicon + apple-touch-icon）

## 🚀 使用与部署

**本地运行**：直接双击打开 `index.html` 即可，无需服务器。

**部署到 GitHub Pages**：

1. 将本目录推送到 GitHub 仓库；
2. 进入仓库 **Settings → Pages**；
3. **Source** 选择部署分支（如 `main`）与根目录 `/`，保存；
4. 稍等片刻即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

**添加到手机主屏幕**：手机浏览器打开页面后，在菜单中选择「添加到主屏幕」即可像 App 一样使用。

## 📁 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件应用（数据、样式、逻辑全部内联） |
| `index.txt` | 与 `index.html` **逐字节一致** 的副本 |
| `favicon.ico` | 浏览器标签页 / 安卓主屏幕图标 |
| `apple-touch-icon.png` | iOS 主屏幕图标 |
| `icon-192.png` / `icon-512.png` | 预留的高清图标 |

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript
- 诗词数据以内嵌 `POEMS` 数组存放，零外部请求
- 已读状态通过 `localStorage` 持久化（键名 `shici_read_v1`）
- 宋体衬线字体 + 米色纸张配色，偏阅读体验
